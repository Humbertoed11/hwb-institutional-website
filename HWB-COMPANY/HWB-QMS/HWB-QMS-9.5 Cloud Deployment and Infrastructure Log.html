Standard Operating Procedure: Cloud Deployment and Infrastructure Log

1.0 Purpose

To define and log the containerized deployment architecture, private registry settings, and automated publishing pipeline for the SigmaFidelity™ web platform (hwbcleaning.com) on Microsoft Azure. This ensures absolute environment parity and zero-defect deployments.

2.0 Scope

Applies to the core web application (hwb_web_app), the private Azure Container Registry (hwbprodacr), and the target Azure App Service (hwb-institutional-website) under Resource Group HWB-Production-RG.

3.0 Cloud & Container Infrastructure Details

  • Production App URL: https://www.hwbcleaning.com
  • Azure Subscription ID: d778faac-02a4-4d74-9881-199994f2bd98
  • Azure Resource Group: HWB-Production-RG
  • Container Registry (ACR): hwbprodacr.azurecr.io (Private)
  • Image Registry Scope: hwbprodacr.azurecr.io/sigmafidelity-web:<tag>
  • Target Web Port: 5000 (Enforced via WEBSITES_PORT=5000)

4.0 Publishing Workflow (Dev to Production)

4.1 Step 1: Local Hardening & Git Commits

Before launching the deployment pipeline, all code modifications (such as API keys, paths, and configurations) must be staged and committed to git to maintain version tracking:

git add .
git commit -m "DEPLOY: <Release Summary>"

4.2 Step 2: Running the Deployment Pipeline

Run the deployment script from the project root directory:

bash scripts/deploy_live_container.sh
System Process Automation

The deployment script builds the production Docker image, pushes it to the private registry (ACR), and authenticates with the Azure Resource Manager API using MSAL to update the Web App's active image and trigger a service reload.

4.3 Step 3: Production Diagnostics Verification

Query Azure's SCM link integrity from the container terminal to verify status:

docker exec hwb_web_app python scripts/diagnostic_azure_deploy.py

Ensure that the Site Operational State prints Running.

5.0 Verification Checklist (Zero-Defect Check)

  • Registry Auth: Does the local Docker client successfully login to hwbprodacr.azurecr.io?
  • Port Binding: Is WEBSITES_PORT in the App settings confirmed at 5000?
  • Database String: Is the production PostgreSQL Flexible Server URL pointing to the live server (sigmajan-server.postgres.database.azure.com)?
  • Smoke Test: Does hitting the dynamic /about route on the live URL return 200 OK with updated branding?
