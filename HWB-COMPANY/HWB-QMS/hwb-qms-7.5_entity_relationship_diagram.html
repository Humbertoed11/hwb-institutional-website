Standard Operating Procedure: Entity Relationship Diagram (ERD)

1.0 Purpose

To define the core PostgreSQL 16.15 relational database schema (`84` public tables) of the HWB Cleaning Services LLC platform across CRM, Commercial Bidding, Workforce Onboarding Vaults, Marketing Campaigns, and Security Auditing.

2.0 Universal Mandates (2026 Baseline)

  1. Physical Truth: Table names and keys match the live PostgreSQL 16.15 schema (`database/schema_engine.py`, Migrations `001`–`050`).
  2. Encrypted Document Vaults: Sensitive tax, ID, and insurance files are stored as AES-256 Fernet `BYTEA` blobs with SHA-256 checksums.
