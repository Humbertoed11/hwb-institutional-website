# Job Description Template

## 1.0 Purpose

This template provides a standardized format for creating and maintaining job descriptions for all positions within HWB Cleaning Services that affect service quality, as required by `[[HWB-SOP-7.2-001 Employee Competence SOP]]`.

## 2.0 Instructions for Use

Complete all sections of this template. Once finalized, the job description should be reviewed with the employee and filed in their employee information file.
