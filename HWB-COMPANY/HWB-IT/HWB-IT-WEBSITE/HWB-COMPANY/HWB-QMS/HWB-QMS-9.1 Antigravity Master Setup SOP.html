Standard Operating Procedure: Antigravity Master Setup

1.0 Purpose

To define the procedure for initializing and hardening the Antigravity agent environment. This ensures that every session starts with the correct SigmaFidelity™ context, mandates, and Tier 6 telemetry connection.

2.0 Universal Mandates (2026 Baseline)

  1. CLI Migration: Legacy Gemini CLI is decommissioned. All operations utilize Antigravity CLI (agy).
  2. Startup Sequence: Every session MUST begin with the execution of bash scripts/startup_master.sh.
  3. Guidance First: If setup fails, pause and ask the CEO before manual patching.
  4. Tier 6 Telemetry: Successful initialization must be logged to the Postgres tactical DB.

3.0 Setup Procedure

  1. Antigravity Verification: Run agy --version to ensure v1.0.1+ is active.
  2. Environment Activation: Initialize the .venv_agent Python environment.
  3. Secret Injection: Load the .env file via inject_production_secrets.py.
  4. Mandate Loading: Verify that all GEMINI.md files are parsed by the agent.
  5. Telemetry Handshake: Execute a test log to SigmaInteractionLog to verify DB connectivity.
Technical Logic

Antigravity uses a Go-based binary which requires the ~/.local/bin directory to be in the shell PATH.

4.0 Verification (Zero-Defect Check)

  • Output of startup_master.sh shows "WATCHDOG ACTIVE".
  • Tier 6 log entry "Session Initialized" is visible in Postgres.
