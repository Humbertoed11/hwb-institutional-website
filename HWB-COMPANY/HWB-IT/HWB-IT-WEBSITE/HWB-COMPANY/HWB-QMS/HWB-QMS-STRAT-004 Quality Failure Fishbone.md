# Root Cause Analysis: General Quality Failure

This diagram provides the standard categorization for analyzing nonconformities (NCRs) and process defects within the HWB Quality Management System.

```mermaid
mindmap
  root((Quality Failure))
    Machines (Equipment)
      Inadequate Maintenance
      Wrong Tool for Task
      Equipment Breakdown
    Methods (SOPs)
      Unclear Instructions
      No Standardized Path
      Bypassing QA Checks
    Materials (Supplies)
      Substandard Chemicals
      Inaccurate SDS Logs
      Supply Chain Delay
    Measurement (Data)
      Inaccurate Audit
      Observer Bias
      Missing KPI Tracking
    Mother Nature (Env)
      Site Constraints
      Adverse Weather
      Utility Failure
    Personnel (People)
      Training Gap
      Communication Error
      Fatigue/Burnout
```

## 2.0 Application
This framework must be used during the **Analyze** phase of every DMAIC project and when completing a **Corrective Action Request (CAR)** via HWB-QMS-FORM-005.
