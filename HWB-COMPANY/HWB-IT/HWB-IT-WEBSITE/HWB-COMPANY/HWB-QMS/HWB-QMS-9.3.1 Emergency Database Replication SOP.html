Standard Operating Procedure: Emergency Database Replication

1.0 Purpose

To provide a clear and simple map of our "Digital Brain" (the SQL database). If all our data is ever lost or deleted, this guide tells you how to build it back so the company can keep working.

2.0 Scope

This applies to the Systems Architect (George) and any IT staff authorized to handle disaster recovery. It covers the four main parts of our database.

3.0 Recovery Procedure (The 4-Part Map)

When rebuilding, you must ensure these four groups of data tables are re-created and linked together.

3.1 The Memory Core (AI Intelligence)

This is where the AI stores its "thoughts" and rules.

  • sigma_kb: The library. It holds all our instruction manuals. It uses special "Vectors" so the AI can find answers instantly.
  • SigmaSystemCore: The memory. It saves what the AI was doing last so it doesn't get confused if the system restarts.
  • SigmaTelemetry: The flight recorder. It logs every action we take so we can find and fix errors.

3.2 The Money Core (Sales & CRM)

This is where we keep track of customers and money.

  • Leads: New business. Tracks name, email, and how much money the deal is worth.
  • Customers: Signed contracts. Holds the address and cleaning schedule for people who already pay us.
  • Opportunities: Active deals. Shows us which customers are almost ready to sign.

3.3 The Field Core (Operations)

This is where we manage the actual cleaning work.

  • WorkOrders: The daily schedule. Shows which team is cleaning which building and saves "after" photos.
  • Services: The "To-Do" list. Lists exactly what tasks are included in a "Janitorial" or "Industrial" clean.
  • Chemicals: Safety tracking. Lists the cleaning liquids we use and makes sure we don't run out.

3.4 The Health Core (Governance)

This is the "Dashboard" that tells us if the system is broken.

  • Uptime: Tracks if the website is working or if it went down.
  • Incidents: A list of every time a mistake happened or a server crashed.
Industrial Note

Always rebuild the "Memory Core" first. Without it, the AI cannot help you find the data for the other three cores.

4.0 Verification (Zero-Defect Check)

  • Are all 41 core tables listed in the new database?
  • Can the AI retrieve a rule from the sigma_kb table?
  • Can the CEO see the active Leads on the dashboard?
