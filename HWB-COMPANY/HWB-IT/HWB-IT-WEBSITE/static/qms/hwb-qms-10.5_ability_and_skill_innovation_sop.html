Standard Operating Procedure: Ability and Skill Innovation

1.0 Purpose

To define the procedure for the AI team to automatically find, create, and upgrade its own "Brains" (Skills) and "Hands" (Abilities). This ensures HWB stays ahead of the market by constantly improving our digital tools and intelligence.

2.0 Definitions

  • Skill: A new set of rules or knowledge (e.g., How to audit a new type of building).
  • Ability: A new technical power or tool (e.g., Mouse tracking, video editing, voice commands).

3.0 Universal Mandates (2026 Baseline)

  1. Friction Detection: If a task is slow or clumsy, the AI must log it as a "Skill Gap."
  2. The Mouse Rule: Abilities that track user behavior (like mouse movements) must be used to make the website simpler and faster.
  3. Recursive Growth: Every session must aim to build at least one small improvement for the next session.

4.0 Procedure

4.1 Finding New Gaps

  1. Watch the Work: If an AI team member fails a task twice, it must query the SigmaAbilities table.
  2. Log the Request: If the tool doesn't exist, the AI logs a new "Research" entry.

4.2 Building the Ability

  1. Drafting: Use the Intuition Engine to plan the code (e.g., JavaScript for mouse tracking).
  2. Testing: Build a small "Sandbox" version first.
  3. HWB Standard: Ensure the new ability uses "Everyday Words" and follows the clinical look.

4.3 Reference Learning (Gold Standard)

  1. The CEO can provide a "Gold Standard" asset.
  2. The AI saves this to the SigmaGold table and uses it as the perfect example for all future work.

5.0 Verification (Zero-Defect Check)

  • New abilities are listed in the Backoffice Dashboard with an "Active" status.
  • 100% of new skills follow the May 1st 2026 documentation standard.

6.0 Notes and Cautions

NoteAbilities like "Mouse Tracking" are for **Optimization**—finding where people get stuck.
CautionNever build an "Ability" that goes against the core HWB safety rules.
