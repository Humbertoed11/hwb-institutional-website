Backend Component Standard

The Technical Catalog for HWB Backoffice elements. This manual lists every component from the top utility bar down to special row actions, mapping their physical paths and logic.

1.0 Three-Tier Navigation Architecture

The backoffice uses a tiered system to separate Identity, Path, and Action.

Tier 1: Clinical Admin Header
Folder Path: HWB-IT-WEBSITE/templates/components/admin_header.html
Logic: Persistent Identity & Session Control (Logo + Logout). Z-Index: 4000.
Tier 2: Command Bar (Breadcrumbs)
Folder Path: HWB-IT-WEBSITE/templates/backoffice_base.html
Logic: Absolute Location awareness. Automatically updates via {% block breadcrumbs %}.
Tier 3: Workspace Menu (Action Stage)
Folder Path: HWB-IT-WEBSITE/templates/components/backend_nav.html
Logic: High-velocity navigation to core modules (Leads, Accounts, Executive, Lab, Manual).
