Job Description Template

1.0 Purpose

This template provides a standardized format for creating and maintaining job descriptions for all positions within HWB Cleaning Services that affect service quality, as required by [[HWB-SOP-7.2-001 Employee Competence SOP]].

2.0 Instructions for Use

Complete all sections of this template. Once finalized, the job description should be reviewed with the employee and filed in their employee information file.

3.0 Job Description Details

Field Description / Content
Position Title [e.g., Cleaning Technician, Site Supervisor]
Department [e.g., Operations]
Reports To [e.g., Cleaning Supervisor, Assistant Operations Manager]
Date Created/Revised [YYYY-MM-DD]
Summary of Position [Brief overview of the role's primary function and contribution to HWB Cleaning Services.]
Key Responsibilities [List the main duties and tasks, including frequency and expected outcomes (e.g., "Perform daily cleaning tasks according to client checklist," "Train new cleaning staff on basic procedures").]
Required Competencies [Specific skills (e.g., equipment operation, chemical handling), knowledge (e.g., safety protocols), and abilities (e.g., physical stamina, attention to detail) required for the role.]
Required Experience [e.g., X years in cleaning, specific industry experience.]
Required Education/Certifications [e.g., High School Diploma, OSHA HazCom certification.]
Physical Demands [Describe physical requirements like lifting, bending, standing for long periods.]
Work Environment [Typical work settings (e.g., client sites, various weather conditions).]
