Standard Operating Procedure: Institutional Documentation Standard

1.0 Purpose

To define the mandatory standard for creating, managing, and modernizing all HWB documented information. This version marks the official transition from Markdown to HTML as the primary source of truth for all SOPs.

2.0 Scope

Applies to all departments and all AI agents. Effective immediately, Markdown (.md) is designated as a LEGACY format. All new documents must be authored in HTML (.html).

3.0 Universal Mandates (The HTML Shift)

  1. HTML First: All new SOPs, guides, and manuals must be created as HTML fragments using the sop_template.html.
  2. The May 1st Baseline: Any document dated before May 1st, 2026, is designated as OUTDATED.
  3. No Synthetic Data: Real-world evidence only.
  4. Surgical Continuity: Use the replace tool for surgical updates to prevent content erosion.

4.0 Prerequisites

  • Master Template: HWB-COMPANY/HWB-QMS/sop_template.html.
  • Clinical Shell: HWB-IT-WEBSITE/templates/sop_base.html.
  • Asset Location: All new SOPs must be saved directly to the appropriate HWB-COMPANY/[DEPT] folder with the .html extension.

5.0 Procedure

5.1 Document Creation (HTML)

  1. Copy the sop_template.html.
  2. Fill in the 0.0 Document Control table and the sop-meta block.
  3. Draft content using Everyday Words.
  4. Use standard HTML tags and SigmaFidelity™ classes.
  5. Save the file in the appropriate department folder.

5.2 Deployment to Compliance Engine

  1. Copy the new HTML file to HWB-COMPANY/HWB-IT/HWB-IT-WEBSITE/static/qms/.
  2. Update the qms_index.json manually to include the new entry.
