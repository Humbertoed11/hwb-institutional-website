1.0 Purpose

This checklist ensures that all required documents are present and maintained in each employee's confidential information file, as per [[HWB-SOP-7.2-001 Employee Competence SOP]] and relevant privacy regulations.

2.0 Instructions for Use

This checklist should be completed upon employee onboarding and reviewed periodically (e.g., annually) or when significant changes occur. All items marked "Required" must be present.
