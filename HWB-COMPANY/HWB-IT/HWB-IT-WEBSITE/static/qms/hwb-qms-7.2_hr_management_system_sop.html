Standard Operating Procedure: HR Management System SOP

1.0 Purpose

To define the structure and governance of the HR department, ensuring all W-2 personnel and 1099 subcontractor trade partners are recruited, deduplicated, onboarded, and trained according to ISO 9001:2026 (ISO 9001:2015+Amd 1:2024) Clause 7.2 (Competence) and Clause 8.4 (Control of Externally Provided Processes).

2.0 Universal Mandates (2026 Baseline)

  1. Third-Person Perspective: All HR documentation and system logs must use the objective 3rd-person standard and plain, everyday English.
  2. Guidance First: If a worker certification is expired, notify executive leadership before suspending field duty.
  3. Zero Duplicate Personnel Records (BUG-122): All workforce recruitment and HR onboarding endpoints must enforce the 5-Pillar Enterprise Deduplication & Smart Merge Engine so returning applicants, subcontractors, and employees update their single master profile rather than creating duplicate database rows.

3.0 Procedure

  1. File Management: Maintain secure digital records for each employee (HWB-FORM-7.2-004) and subcontractor partner inside PostgreSQL 16.15.
  2. Workforce & Subcontractor Intake Deduplication:
    • When a W-2 candidate applies via POST /api/v1/workforce/apply or a 1099 subcontractor registers via POST /api/v1/workforce/subcontractor, the system checks existing records by 10-digit phone number, lowercase email, and normalized business name.
    • If the applicant or subcontractor is already registered, the system preserves the original record ID and registration date, merges any updated trade specialties, crew size, or shift preferences, sends an updated Reference ID receipt email (APP-#00XX or SUB-#00XX) to the registrant, and displays the privacy-safe Already Registered — Profile Updated banner on /work-with-us.
    • Manual backoffice subcontractor creation (POST /api/v1/workforce/subcontractors) blocks duplicate phone numbers, emails, or company names with an HTTP 409 Conflict notice.
  3. Employee Onboarding & Academy Assignment Deduplication:
    • Promoting a candidate via POST /api/v1/hr/onboard checks "Employees" by applicant_id, 10-digit phone, and email. Repeat calls update role and pay rate while preserving the existing employee badge (HWB-EMP-####).
    • Assigning training courses via POST /api/v1/academy/assign checks "AcademyEnrollments" for existing enrollments and reuses the active magic_token instead of creating duplicate training rows.
  4. Certification Tracking: All equipment operators and field crews must complete assigned SigmaAcademy™ safety modules before deployment.

4.0 Verification (Zero-Defect Check)

  • Quarterly audit of training records in "AcademyEnrollments".
  • 100% compliance with GHS Hazard Communication training.
  • Zero duplicate rows across "SubcontractorPartners", "JobApplicants", and "Employees" verified by scripts/test_labor_recruitment_and_cyber_suite.py (5/5 tests passing).
