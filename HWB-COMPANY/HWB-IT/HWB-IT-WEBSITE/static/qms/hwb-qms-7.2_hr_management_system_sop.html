ISO 9001 Clause 7.1.2 (People)

Standard Operating Procedure: HR Management System SOP

1.0 Purpose

To define the structure and governance of the HR department, ensuring all personnel are recruited and trained according to ISO 9001:2015 Clause 7.2 (Competence).

2.0 Universal Mandates (2026 Baseline)

  1. Third-Person PERSPECTIVE: All HR documentation must use the 3rd person standard.
  2. Guidance First: If a certification is expired, ASK the CEO before suspending field duty.

3.0 Procedure

  1. File Management: Maintain secure files for each employee (HWB-FORM-7.2-004).
  2. Competence: Identify necessary skills for each role.
  3. Certification Tracking: All equipment operators (M20, S20) must be certified before deployment.

4.0 Verification (Zero-Defect Check)

  • Quarterly audit of training records.
  • 100% compliance with GHS Hazard Communication training.
