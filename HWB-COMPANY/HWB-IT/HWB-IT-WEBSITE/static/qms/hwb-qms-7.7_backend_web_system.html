Backend Web System Sequence

The Technical Sequence for the HWB server. This manual maps how data flows from the internet through our routing, logic, and PostgreSQL 16.15 persistence layers.

1.0 The Request Flow (Top-to-Bottom)

Every visitor interaction follows this exact 8-step sequence within our infrastructure.

1. Edge Perimeter & Origin Shield (Pincer Shield)
Gateway: Cloudflare Anycast TLS 1.3 + Azure App Service IP Whitelist
Logic: Enforces Full (Strict) SSL, 7-day static edge caching, and blocks direct origin bypasses before routing to Gunicorn (24 concurrency slots: 3 workers × 8 threads).
GATEWAY
2. Routing Layer (The App Engine)
Folder Path: HWB-COMPANY/HWB-IT/HWB-IT-WEBSITE/main_app.py
Logic: The Flask Core. Matches URLs (e.g., /admin/operations) to specific Python functions.
FLASK
3. Executive Handshake (Auth)
Folder Path: main_app.py (using Flask-Login)
Logic: Prevents unauthorized access to CRM and Admin views. Validates the Microsoft Entra token.
SECURE
4. Agentic Orchestrator
Folder Path: HWB-IT-WEBSITE/sigma_orchestrator.py
Logic: Coordinates work between George (Architect) and Silas (CRM) for complex data tasks.
AI BRAIN
5. Lead Ingestion Logic
Folder Path: main_app.py (def get_quote)
Logic: Sanitizes web input, runs the $0.12 price formula, and prepares database insertion.
CAPTURE
6. Persistence Layer (Database)
Folder Path: core/services/database.py
Logic: Commits the sanitized lead data to the "Leads" table in PostgreSQL.
DATA
7. Transmission Hub (Email/Teams)
Folder Path: core/services/email_service.py
Logic: Notifies the HWB team via MS Teams and stages the Lead Alert in the Outbox.
SIGNAL
8. Telemetry Archive (Tier 6)
Folder Path: scripts/push_telemetry.py
Logic: Finalizes the transaction by logging the execution state to the "SigmaTelemetry" table.
SAFE
