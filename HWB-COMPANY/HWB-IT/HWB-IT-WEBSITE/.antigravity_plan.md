# QMS Web Manual Display Hardening

This plan outlines the visual and structural modernization of the HWB Institutional Operating Manual web interface. It addresses usability concerns raised under **BUG-032** by applying the **2026 Polish Standard**, **High-Density Hardening**, and the **SigmaFidelity™ Salesforce-Tier UI System**.

## User Review Required

> [!IMPORTANT]
> The primary objective is to replace the static, hardcoded template layout with a dynamic, user-friendly navigation shell. We will load `qms_index.json` dynamically in all QMS routes so that the sidebar behaves as a live, interactive navigator for all 168+ compiled SOP documents.

> [!TIP]
> All changes are built using native, semantic HTML and vanilla CSS. There are zero external dependencies introduced, ensuring compliance with strict security and high performance.

## Proposed Changes

### Web Application Controller

#### [MODIFY] [main_app.py](file:///home/humbertoed/gemini_projects/HWB-COMPANY/HWB-IT/HWB-IT-WEBSITE/main_app.py)
*   Modify `manual_index()` and `view_sop()` to always load the dynamic SOP catalog from `qms_index.json` and group them by department.
*   Pass `sops_by_dept` and the active `filename` to the templates so the layout can dynamically render the sidebar index with the correct active states.

### Layout & Page Templates

#### [MODIFY] [sop_base.html](file:///home/humbertoed/gemini_projects/HWB-COMPANY/HWB-IT/HWB-IT-WEBSITE/templates/sop_base.html)
*   **Aesthetic Modernization:** Introduce clinical slate backgrounds (`#f8fafc`), cap layout border-radius to `1.25rem` (20px), and set up the base grid framework for dynamic responsiveness.
*   **Dynamic Sidebar:** Replace hardcoded static navigation links with an iterative, interactive sidebar rendering all departments and SOPs directly from the Flask context.
*   **Live Search Filter:** Embed a lightning-fast client-side search bar inside the sidebar. Allows instant real-time filtering of all SOP titles, IDs, and departments.
*   **Collapsible Department Sections:** Provide SVG-based accordion dropdowns for high-density document groupings.
*   **Salesforce-Tier Controls:** Add vertically compressed utility buttons (36px high, sharp 6px border-radius, 600 weight text) for instant printing, index returns, and configuration.

#### [MODIFY] [qms_manual_index.html](file:///home/humbertoed/gemini_projects/HWB-COMPANY/HWB-IT/HWB-IT-WEBSITE/templates/qms_manual_index.html)
*   **Enterprise Tab Rack:** Implement a top-level tab controller (`.sigma-tab-rack`) to filter departments dynamically (All, Operations, EHSQ, E&O, etc.).
*   **Grid Modernization:** Redesign the document index to use high-density cards with elegant hover transitions, soft shadow depth, and micro-animations.
*   **Compliance Indicator Pills:** Standardize compliance status indicators using soft-pastel background pills (muted green for `UPDATED`, muted yellow for `OUTDATED`).
*   **Micro-interactions:** Add interactive search focus states and subtle focus-slide highlights.

#### [MODIFY] [qms_shell.html](file:///home/humbertoed/gemini_projects/HWB-COMPANY/HWB-IT/HWB-IT-WEBSITE/templates/qms_shell.html)
*   Wrap the injected document content in a smooth transition container (`.sigma-view-fade`).
*   Cap embedded header scales to exactly `1.5rem` (Semi-Bold) for high-density, professional visual flow.
*   Inject clean Next/Previous SOP utility navigation bars to support sequential read-through of department procedures.

2.  **Visual Layout Audit:**

4.  **PDF/Print Output:** Trigger the "Print" action and ensure the sidebar, top header, and navigation buttons are excluded, leaving a perfectly formatted, standard-compliant document for official audit.
