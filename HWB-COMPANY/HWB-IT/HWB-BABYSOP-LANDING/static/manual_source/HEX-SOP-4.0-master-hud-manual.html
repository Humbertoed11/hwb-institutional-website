Master Operating Procedure: Heads-Up Display (Layer 3) Specification

Scope: Establishes global constraints and layout specifications to implement a Salesforce-tier, keyboard-first visual interface for the HEXGROWTH HUD viewports.

1.0 Purpose & Adaptive Semantic Zoom

To define visualization standards across all grid rendering resolutions:

  • Level 1 (Regional Zoom): Rendered as high-level density heatmaps.
  • Level 2 (District Zoom): Renders individual hexagonal tessellation boundaries.
  • Level 3 (Parcel Zoom): Renders targeted parcel outlines, active connection paths, and sidebars.

2.0 Layout Structure & Interface Overlays

The Master HUD layout is split into four primary interactive layers:

  1. Visual Engine (Center Canvas): Displays MapLibre GL background tiles overlaid with the dynamic H3 Resolution 11 hexagonal honeycomb, pulsing radar flags, and active highway egress lines.
  2. The Stick Ledger (Right Sidebar): Offers real-time title data, property boundaries, and adjacent development alarm systems.
  3. George Bytes Console (Bottom panel): Displays live web crawler operations, system telemetry logs, and a dynamic PDF/HTML opportunity report compiler.
  4. Tactical Overlays: Provides a vertical Alpha metric meter, a scrolling hazard ticker, and the interactive legend panel.

3.0 Visual Vocabulary & Color Code Mappings

Standardized threshold highlights for opportunity scores:

  • Emerald Green (8.0 to 10.0): Prime feasibility location (strong development potential).
  • Amber Yellow (4.0 to 7.9): Moderate feasibility location (potential zoning/utility friction).
  • Crimson Red (0.0 to 3.9): Low feasibility location (development blockages/high hazard risk).

All status badges must use 10% opacity color fills with a solid 1px outer border of the same color. High-saturation, solid-color status badges are prohibited.

4.2 Typography & Input Standards

  • Label Placement: Inputs must sit at a tight 4px vertical proximity to their corresponding label to form a single unit.
  • Font-Weight: Standardize label font-weight to exactly 500. Header elements are capped at 1.5rem (Semi-Bold).
  • No Icons in Labels: Icons within input labels are strictly prohibited. Icons are reserved for navigation bars and state alerts.

4.3 Interactive Element Rigidity

  • Button Dimensions: Standardize button height to exactly 32px to 40px to maximize screen density.
  • Corners: Button and input border-radius is capped at exactly 6px. Master layout cards are capped at 1.25rem (20px).
  • SVG Controls: Use vector SVGs for close actions and icons. Raw HTML entities are prohibited.
  • Tab Rack Layout: Tab switching must use a tight horizontal layout class (.sigma-tab-rack) with a 3px active indicator accent.

5.0 Keyboard Command Shortcuts

To maximize speed, the interface is built for keyboard-first commands (CMD+K / Ctrl+K):

  • /go [H3-Address]: Fly the map view to specific coordinates.
  • /lobe [1-7]: Instantly toggle specific map data scores.
  • /search [Developer-Name]: Highlight target holdings on the grid.
