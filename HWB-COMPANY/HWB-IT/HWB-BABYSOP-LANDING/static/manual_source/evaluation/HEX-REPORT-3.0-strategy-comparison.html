HEXGROWTH: Strategy Comparison (06/03/2026)

A direct strategy comparison report analyzing the current H3 hexagon grid system versus the master reference parcel API strategy.

1.0 The Challenge

The current system is fast and free, but it does not represent real-world legal property boundaries. Real estate developers buy properties, not perfect hexagons. However, switching fully to real-world parcels is expensive and slows down performance.

2.0 Pros & Cons of the Two Plans

  • H3 Hexagons (Current Plan): Fast rendering, zero API cost, but low utility because it lacks exact boundary data.
  • Real Parcels (Master Plan): High utility and exact legal data, but high monthly cost ($1,970/mo) and slow rendering speeds.

3.0 Recommendation: The Hybrid Plan

Use the hexagon grid for macro-level screening (finding hot neighborhoods or general traffic trends) and load actual parcel boundaries only when the developer zooms in to inspect a specific property.
