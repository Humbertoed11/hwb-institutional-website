HEXGROWTH Deep Search Implementation Plan

This document details the next step after a user saves a target lot to the review list. Once a lot is saved, the system needs to run a deep search. This search gathers county land papers, city rules, and soil reports for the area to determine if the lot is safe and ready for development.

ℹ️ PLAN OBJECTIVE

The goal is to automate the extraction and analysis of local public records using Lobe 11 (Scout Brain) and Lobe 8 (Inference Brain). This removes the need for manual record searches and speeds up land reviews.

1.0 Deep Search Process Workflow

When the user clicks the deep search button for a saved lot, the system goes through these steps:

  1. User Action: The user clicks "Start Deep Search" on the lot review card in the sidebar.
  2. Job Creation: The frontend calls the server endpoint /api/v1/deep-search/initiate, which adds a job record with a status of "Running" and returns a job tracking ID.
  3. Asynchronous Extraction (Lobe 11): The server starts a background worker task that targets county database systems and land record portals.
  4. Logical Analysis (Lobe 8): Once files are collected, the text is scanned for zoning, owner rules, and environmental issues.
  5. Results Save: The worker writes findings to the database and updates the job status to "Completed".
  6. User Notification: The map view and sidebar update to show the search results are ready for inspection.

2.0 Lobe Allocation & Duties

2.1 Lobe 11 (Scout Brain) - Record Gathering

Lobe 11 connects directly to external county clerk websites, public GIS map layers, and environmental registries. It is responsible for:

  • File Downloads: Finding and downloading PDF files of deeds, land transfers, and zoning rules matching the lot coordinates.
  • API Probes: Pinging city planning databases to retrieve utility capacity sheets and sewer line layouts.
  • Data Cleanup: Removing unneeded formatting and turning PDF/HTML contents into clean, readable text.

2.2 Lobe 8 (Inference Brain) - Rule Verification

Lobe 8 receives the clean text from Lobe 11 and performs logic checks to assess site viability:

  • Zoning Rules: Checking if the local codes allow the planned building height, lot coverage, and noise levels.
  • Owner Agreements: Reading property deeds to ensure there are no active covenants that block construction or specify land usage limits.
  • Soil & Water Risks: Checking public logs for historical spill records, soil instability, or high water tables nearby.
  • Score Calculation: Generating a final feasibility rating (0 to 100) based on identified risks.

3.0 Database Schema Extensions

Two new tables are required to track deep search actions and store the final extraction reports:


-- Tracks active and historic deep search requests
CREATE TABLE "HEX_DeepSearchJobs" (
    id SERIAL PRIMARY KEY,
    lot_id INTEGER REFERENCES "HEX_TargetLotReviews"(id) ON DELETE CASCADE,
    job_status VARCHAR(50) DEFAULT 'Pending', -- Pending, Running, Completed, Failed
    error_message TEXT,
    started_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    completed_at TIMESTAMP
);

-- Stores analyzed results and risk factors
CREATE TABLE "HEX_DeepSearchResults" (
    id SERIAL PRIMARY KEY,
    job_id INTEGER REFERENCES "HEX_DeepSearchJobs"(id) ON DELETE CASCADE,
    lot_id INTEGER REFERENCES "HEX_TargetLotReviews"(id) ON DELETE CASCADE,
    zoning_classification VARCHAR(100),
    allowable_height_ft INTEGER,
    soil_risk_level VARCHAR(50), -- Low, Medium, High
    easements_found TEXT,
    owner_restrictions TEXT,
    feasibility_score INTEGER,
    report_summary TEXT,
    scouted_documents JSONB, -- Array of document links and metadata
    analyzed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

4.0 UI & UX Integration

The user interface must be upgraded to support and display the deep search results:

  • Sidebar Status Indicator: The review list will show a rotating loading circle next to lots undergoing active search. The background of the lot list item will flash gently during processing.
  • Interactive Report Card: Clicking a lot with a completed search opens a details card showing the feasibility score, a text summary of finding logs, and links to download original documents.
  • Map Overlay Layers: Completing a search unlocks toggle switches on the map HUD to display the lot's sewer lines, water mains, and zoning boundary outlines.
