Standard Operating Procedure: Universal H3 Grid (Layer 0)

1.0 Purpose

To define the technical standard for the physical foundation of HEXGROWTH. Layer 0 utilizes the Uber H3 indexing system to convert the spherical earth into a manageable, mathematical grid of hexagons.

2.0 Resolution Standard

HEXGROWTH utilizes Resolution 11 as the primary analysis scale.

  • Average Edge Length: ~25 meters.
  • Average Area: ~0.002 km² (Approx. 0.5 acres).
  • Rationale: This resolution aligns perfectly with standard real estate parcel sizes, allowing for precise utility and regulatory attribution.

3.0 The Universal Location Key

The h3_address (e.g., 8b2681120000fff) serves as the primary key for all data across the 7 Brains. This ensures that whether we are looking at TxDOT traffic or local zoning, we are referencing the exact same physical space.

4.0 Database Schema

The grid is stored in the HEX_Grid_Res11 table within the PostGIS core.

  • h3_address: Text (Primary Key).
  • geom: PostGIS Geometry (Polygon, 4326).
  • city_name: Text (Temporal filter).
Industrial Consistency

All "Alpha Votes" from the 7 Lobes MUST be tied to an H3 index. No data is permitted to exist in the Spine without a corresponding Layer 0 key.
