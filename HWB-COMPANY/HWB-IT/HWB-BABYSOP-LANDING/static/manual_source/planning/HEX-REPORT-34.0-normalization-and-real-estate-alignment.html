Institutional Normalization & Real Estate Alignment: Global Implementation Plan

This document records the approved layout normalization and real estate terminology alignment plan across the HexGrowth application. It replaces tech-centric metaphors with standard industry terms and normalizes color palettes, button heights, and data tables to improve the operator's experience.

ℹ️ OPERATOR OBJECTIVE

To implement standard real estate terminology globally and unify the visual design guidelines (colors, buttons, tables) across all viewports and compiled reports.

1.0 Terminology Realignment Mapping

The application is updated to replace all references to AI "Lobes" or "Brains" with institutional real estate categories:

System Lobe Index Legacy Name Normalized Real Estate Term
L1 City Planning Lobe / City Brain Zoning & Municipal Entitlements
L2 TxDOT Traffic Lobe / TxDOT Brain Access, Egress & Traffic Capacity

2.0 Layout and Interaction Standards

2.1 Color Status Normalization

All status indicators, log highlights, map hexes, and print layouts must use these standardized hex codes:

  • Optimized / Success: #10b981 (Emerald Green) or #06b6d4 (Cyan for special projects).
  • Review / Pending: #f59e0b (Amber Orange).
  • Fatal Blockage / Halted: #ef4444 (Rose Red).

2.2 Button Sizing Standards

Buttons inside the interface are normalized to two strict height profiles:

  • Primary Action Buttons: 36px height (e.g., Play, Pause, Submit).
  • Inline / Small Buttons: 28px height (e.g., inside tables and popup actions).
  • All buttons require font-weight: 600.

2.3 Data Grid Layout

All data tables must inherit the .sigma-data-grid class, ensuring 12px body text, 11px uppercase bold headers, left-aligned text, right-aligned numbers, and uniform grey borders.
