Standard Operating Procedure: Pulse Brain Neural Plan & Competitor Radar

1.0 Purpose

This QMS document establishes the structural design, data schema, API routing, and HUD viewport specifications for the HEXGROWTH Pulse Brain (Lobe 6). The Pulse Brain serves as the primary system radar for hyper-local sentiment shifts, commercial/retail flight indicators, and competitor developer activities.

2.0 Architectural Objectives

  • Automate Risk Mapping: Identify negative municipal shifts (such as anchor tenant flight and sports franchise relocations) before public valuations adjust.
  • Competitor Intelligence Registry: Profile local development companies, tracking their acquisitions, planning filings, and buying criteria.
  • Telemetry Verification: Maintain active link testing (status and latency checks) for municipal and social sources.

3.0 Database Core Expansion (Tier 6)

The following tables are initialized within the Monolithic SQL Brain to persist Pulse metrics:


-- 1. Scouting & Interface Uptime Registry
CREATE TABLE IF NOT EXISTS "HEX_Scout_Registry" (
    id SERIAL PRIMARY KEY,
    municipality_name VARCHAR(150) NOT NULL,
    department_name VARCHAR(150) NOT NULL,
    source_type VARCHAR(100) NOT NULL,
    endpoint_or_contact TEXT UNIQUE NOT NULL,
    scouting_status VARCHAR(50) DEFAULT 'Identified',
    latency_ms INTEGER,
    scouted_notes TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    last_scouted TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. Competitor Developer Profiles
CREATE TABLE IF NOT EXISTS "HEX_DeveloperProfiles" (
    id SERIAL PRIMARY KEY,
    company_name VARCHAR(255) UNIQUE NOT NULL,
    estimated_aum NUMERIC(15, 2),
    target_asset_class VARCHAR(100),
    acquisition_criteria JSONB,
    contact_info JSONB,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 3. Competitor Intent & Purchases Log
CREATE TABLE IF NOT EXISTS "HEX_DeveloperIntent" (
    id SERIAL PRIMARY KEY,
    company_id INTEGER REFERENCES "HEX_DeveloperProfiles"(id) ON DELETE CASCADE,
    intent_type VARCHAR(50) NOT NULL, -- 'Planning', 'Purchasing', 'Seeking'
    target_parcel_id VARCHAR(100),
    description TEXT NOT NULL,
    estimated_value NUMERIC(15, 2),
    source_url TEXT,
    recorded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 4. Social Sentiment & Decline Opportunities
CREATE TABLE IF NOT EXISTS "HEX_PulseOpportunities" (
    id SERIAL PRIMARY KEY,
    h3_address VARCHAR(15),
    platform VARCHAR(50) NOT NULL,
    post_url TEXT UNIQUE NOT NULL,
    post_content TEXT,
    sentiment_score NUMERIC(3, 2) NOT NULL, -- 0.0 (High Risk) to 10.0 (High Opportunity)
    extracted_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
